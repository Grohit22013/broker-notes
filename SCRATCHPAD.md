An "Ask my notes" agent stays an optional stretch goal.                                                                         |
| 2026-11-28 | Mobile-first UI with a bottom tab bar on phones                                                                   | Brokers often write notes on the go, between client meetings.                                                                                                                                                         |

| 2026-11-28 | Multi-job CI with one required "CI passed" gate                                                                   | Each check reports separately, so it's clear what failed. Jobs run in parallel, and branch protection only needs to require one check.                                                                                |
| 2026-11-28 | Auth.js v5 (beta) with Credentials and **JWT** sessions, pinned to `5.0.0-beta.32`                                | The assignment asks for email/password. JWT means no session table, and the edge middleware can check the token without a DB call. Pinned because it's a beta.                                                        |
| 2026-11-28 | `bcryptjs`, not native `bcrypt`                                                                                   | Pure JavaScript, so there's no native build step on Windows or Vercel. Cost 12.                                                                                                                                       |
| 2026-11-28 | Constant-time login (compare against a dummy hash when the user doesn't exist), one generic error message         | Stops attackers from finding out which emails are registered.                                                                                                                                                         |
| 2026-11-28 | Same-site-only post-login redirects (`safeRedirect`); the middleware builds a relative `callbackUrl`              | Prevents open redirects. | 2026-11-28 | **Tiptap 3.34.0**, not v2 or the newest 3.35.1                                                                    | v3 is the current major version (StarterKit includes Link and Underline; TableKit). | 2026-11-28 | Store the document as Tiptap JSON, plus a plain-text copy                                                         | JSON keeps the formatting exact. The plain text gives fast search and list snippets without parsing JSON.                                                                                                             |
| 2026-11-28 | Soft delete (`deletedAt`)                                                                                         | File notes are compliance records (ASIC RG 273). Deleting hides a note but keeps the record.                                                                                                                          |
| 2026-11-28 | Version snapshots throttled to 1 per 5 minutes                                                                    | Autosave fires every ~1.5s, so a snapshot per save would flood the history. One every 5 minutes is a useful audit trail at a fraction of the rows.                                                                    |
| 2026-11-28 | Autosave **max wait** plus **save when the page is hidden**                                                       | Found with screenshots: a plain debounce never fires while someone types steadily, so switching apps on a phone could lose work.                                                                                      |
| 2026-11-28 | Send a plain JSON copy of the doc (`toPlainDoc`) to the server action                                             | ProseMirror uses null-prototype `attrs`, which React's server-action serializer sends as unreadable "temporary references". Formatted notes failed to save until this was fixed (found by E2E).                       |
| 2026-11-28 | Playwright E2E on desktop and **mobile (Pixel 7)**, against real Postgres in CI                                   | Proves the core flow and cross-user isolation on both form factors. Browsers live on D: locally because C: is short on space.                                                                                         |
| 2026-11-28 | Keep shadcn's official `cn` package                                                                               | I briefly removed it, mistaking it for an unrelated package. | 2026-11-28 | Note details added in Phase 3 (not Phase 4)                                                                       | Filtering by stage, type, tags and follow-ups needs those fields to exist. ## Open issues, TODOs and known limitations

- **Next.js 15.5 production navigation stall (worked around).** On server-rendered list pages (Cases, Tasks, Clients, Audit log), a client-side navigation that only changes the query string intermittently never commits in production builds: the RSC response arrives (about 200 ms, status 200, no errors) but the router doesn't apply it. Development mode is unaffected; cross-page navigation works. Ruled out: network, database latency, prefetching, hydration timing, the search form, our task-list state. Workaround: `FilterChip` renders plain `<a>` links (a full page load, which is reliable and fine for server-rendered pages). Reproduced on `main` (Phase 9), so it isn't specific to tasks. Revisit on the next Next.js upgrade.
- **Low disk on the dev machine's C: drive** caused `ENOSPC` test failures; Playwright output and temp now go to D:.
- Opening a seeded demo note shows "Unsaved changes" briefly: Tiptap normalises the hand-written seed JSON and autosaves once. Harmless.

- `npm audit` reports issues in the copy of `postcss` that ships inside Next 15. It only runs at build time, on our own CSS, so the risk is low. Fixing it needs Next 16 (a breaking upgrade), so it's deferred and will be reviewed before deploy.
- The dev machine's C: drive ran out of space during setup. Clearing the npm cache freed about 1.8 GB. Consider `npm config set cache D:\npm-cache`.
- `/notes/new` shows a 404 until Phase 2.
- **Rotate the Neon DB password before deploying.** The current connection string was shared in the AI chat.
- `npm audit` lists high-severity advisories in `effect` and `deepmerge-ts`, which come from the **Prisma CLI's** config loader (`prisma` → `@prisma/config`). That's dev and migration tooling only, never in the runtime bundle. Waiting for a patched Prisma 6 release, which Dependabot will raise.
- The editor page loads 179 kB of JavaScript (Tiptap and ProseMirror). That's acceptable for the main editing screen; the toolbar could be lazy-loaded later if needed.
- No version-history UI yet. Snapshots are already recorded; the history drawer arrives in Phase 4.
- **Stale remote branches** (`phase-0/setup`, `phase-1/auth`, two old Dependabot branches) need deleting. The AI's attempt to delete remote branches was blocked by the permission system, so the owner should run `git push origin --delete …`. Auto-delete on merge is on from now.
- Finalising can't be undone by design. Deleting a finalised note is still allowed (it's a soft delete, so the record is kept).
- Next.js warns it "inferred the workspace root" because of a stray `package-lock.json` in the user's home folder (outside the repo). It's harmless; setting `outputFileTracingRoot` triggered a Tailwind ESM-loading bug, so it's left unset.
- Local dev machine: C: is almost full, so `apps/web/.next` is a junction to `D:\brokernotes-build` (local only, gitignored).
- ~~There's no login rate limiting yet.~~ Done in Phase 5 (API throttling on auth routes). Serverless needs a shared store (for example Upstash) for that, so it's a candidate for Phase 6.
- No "forgot password" or email verification; there's no email provider, which is out of scope for the assignment.
