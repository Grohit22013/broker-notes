## Decisions log

| Date       | Decision                                                                                                         | Why                                                                                                                                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-11-28 | Target **Australian** mortgage brokers                                                                           | Research found the hiring group (Stephen Ventures / Carisma) processes loans for AU brokers, and the linked startup Finobi builds AI file notes for AU advisers. ASIC RG 273 makes file notes a compliance need.      |
| 2026-11-28 | Postgres on **Neon** with **Prisma 6**                                                                           | Free tier, works well with Vercel, and gives type-safe queries. Prisma 6 keeps the simpler `url`/`directUrl` config.                                                                                                  |
| 2026-11-28 | **Next.js 15.5**, not 16                                                                                         | A stable, well-known setup that works with Auth.js v5 and Tiptap.                                                                                                                                                     |
| 2026-11-28 | AI through **OpenRouter** (free or cheap models)                                                                 | Keeps cost close to zero. The model is set in env, so it can be swapped without code changes.                                                                                                                         |
| 2026-11-28 | **One structured AI call** per analysis, no agent in the core app                                                | One call is cheaper, faster and more reliable on free models than a multi-step agent. An "Ask my notes" agent stays an optional stretch goal.                                                                         |
| 2026-11-28 | Mobile-first UI with a bottom tab bar on phones                                                                  | Brokers often write notes on the go, between client meetings.                                                                                                                                                         |
| 2026-11-28 | Branch per phase, PR into `main`, and the owner merges                                                           | Every change gets reviewed, and CI must pass before merging.                                                                                                                                                          |
| 2026-11-28 | Multi-job CI with one required "CI passed" gate                                                                  | Each check reports separately, so it's clear what failed. Jobs run in parallel, and branch protection only needs to require one check.                                                                                |
| 2026-11-28 | Auth.js v5 (beta) with Credentials and **JWT** sessions, pinned to `5.0.0-beta.32`                               | The assignment asks for email/password. JWT means no session table, and the edge middleware can check the token without a DB call. Pinned because it's a beta.                                                        |
| 2026-11-28 | `bcryptjs`, not native `bcrypt`                                                                                  | Pure JavaScript, so there's no native build step on Windows or Vercel. Cost 12.                                                                                                                                       |
| 2026-11-28 | Constant-time login (compare against a dummy hash when the user doesn't exist), one generic error message        | Stops attackers from finding out which emails are registered.                                                                                                                                                         |
| 2026-11-28 | Same-site-only post-login redirects (`safeRedirect`); the middleware builds a relative `callbackUrl`             | Prevents open redirects. Also fixes a bug found in the end-to-end check, where Auth.js's absolute callbackUrl was rejected and the broker landed on /notes instead of the page they asked for.                        |
| 2026-11-28 | Zod kept out of client bundles (password limits live in `lib/auth/constants.ts`)                                 | The /register page JavaScript dropped from 27.3 kB to 2.9 kB.                                                                                                                                                         |
| 2026-11-28 | **Tiptap 3.34.0**, not v2 or the newest 3.35.1                                                                   | v3 is the current major version (StarterKit includes Link and Underline; TableKit). Pinned to the newest release that's at least 2 weeks old, for stability.                                                          |
| 2026-11-28 | Store the document as Tiptap JSON, plus a plain-text copy                                                        | JSON keeps the formatting exact. The plain text gives fast search and list snippets without parsing JSON.                                                                                                             |
| 2026-11-28 | Soft delete (`deletedAt`)                                                                                        | File notes are compliance records (ASIC RG 273). Deleting hides a note but keeps the record.                                                                                                                          |
| 2026-11-28 | Version snapshots throttled to 1 per 5 minutes                                                                   | Autosave fires every ~1.5s, so a snapshot per save would flood the history. One every 5 minutes is a useful audit trail at a fraction of the rows.                                                                    |
| 2026-11-28 | Autosave **max wait** plus **save when the page is hidden**                                                      | Found with screenshots: a plain debounce never fires while someone types steadily, so switching apps on a phone could lose work.                                                                                      |
| 2026-11-28 | Send a plain JSON copy of the doc (`toPlainDoc`) to the server action                                            | ProseMirror uses null-prototype `attrs`, which React's server-action serializer sends as unreadable "temporary references". Formatted notes failed to save until this was fixed (found by E2E).                       |
| 2026-11-28 | Playwright E2E on desktop and **mobile (Pixel 7)**, against real Postgres in CI                                  | Proves the core flow and cross-user isolation on both form factors. Browsers live on D: locally because C: is short on space.                                                                                         |
| 2026-11-28 | Keep shadcn's official `cn` package                                                                              | I briefly removed it, mistaking it for an unrelated package. It's published by shadcn (`shadcn-ui/cn`), so it was restored, and components import it through `@/lib/utils` so there's one place to change it.         |
| 2026-11-28 | Note details added in Phase 3 (not Phase 4)                                                                      | Filtering by stage, type, tags and follow-ups needs those fields to exist. Phase 4 extends the same panel with clients, key figures, finalise and history.                                                            |
| 2026-11-28 | Filter state in the **URL**, parsed leniently with Zod                                                           | Shareable and bookmarkable, works with back/forward and reloads. Hand-edited or garbage params are ignored instead of causing errors.                                                                                 |
| 2026-11-28 | Follow-ups stored as **local midnight in Australia/Sydney**                                                      | A follow-up is a calendar day, not an instant. Computing "due today" and "overdue" in the broker's time zone (with daylight saving) avoids off-by-one-day bugs from UTC servers.                                      |
| 2026-11-28 | Client-side taxonomy lists, with a compile-time check against the Prisma enums                                   | Client components get labels without bundling Prisma, and `tsc` fails if the lists drift from the enums.                                                                                                              |
| 2026-11-28 | Search uses `ILIKE` (Prisma `contains`, insensitive) for now                                                     | Plenty fast for a broker's notes (hundreds per user). Full-text search or `pg_trgm` is a later optimisation if needed.                                                                                                |
| 2026-11-28 | Details save instantly and optimistically, with rollback on error                                                | No separate "Save" step for small fields. Server actions run in order, so rapid changes can't arrive out of order.                                                                                                    |
| 2026-11-28 | **Squash-merge only + linear history** on `main`                                                                 | Dependabot PRs merged on top of #24 (which already contained their changes) produced a tangle of merge commits. Each PR now lands as one commit titled with the PR title. History is left as it was; no force-push.   |
| 2026-11-28 | Snapshot the **previous** state, not the new one                                                                 | Found by E2E: snapshotting the new content (throttled to 5 minutes) meant wording written and replaced within a window never reached history. Now the content about to be overwritten is saved.                       |
| 2026-11-28 | Finalised-note rules enforced **on the server** (`lockedFieldIn`, `canEditContent`)                              | A disabled input can be bypassed. Server actions reject content edits and locked fields on finalised notes.                                                                                                           |
| 2026-11-28 | Workflow fields (stage, follow-up, tags, pin) stay editable after finalising                                     | They describe what happens next, not what was recorded. The record itself (title, body, type, client, figures) is locked, and corrections are amendments.                                                             |
| 2026-11-28 | Key figures as validated JSON (`keyFigures`), not columns                                                        | Optional, evolving set of fields; Zod-validated on read and write; nothing in it needs indexing yet.                                                                                                                  |
| 2026-11-28 | CSV import is client-parsed (papaparse) and **server re-validated**                                              | The preview gives instant feedback; the server never trusts the browser's validation. Duplicates are skipped, never overwritten.                                                                                      |
| 2026-11-28 | CSV export escapes `= + - @ \t \r` cells                                                                         | A client name like `=HYPERLINK(…)` would otherwise run as a formula in Excel (OWASP CSV injection).                                                                                                                   |
| 2026-11-28 | Local Playwright limited to 3 workers                                                                            | Each sign-up runs two bcrypt (cost 12) hashes. Too many parallel browsers starved the CPU and registrations timed out. CI uses 2 workers.                                                                             |
| 2026-11-28 | Back to **merge commits** (squash off, linear history off)                                                       | The owner prefers each phase's individual commits on `main`, as in Phases 1–3.                                                                                                                                        |
| 2026-11-28 | **Separate backend: NestJS REST API + Next.js frontend** in an npm-workspaces monorepo                           | The owner asked for a separate frontend and backend. A monorepo keeps one PR flow, one CI pipeline and shared types/schemas, so the two sides can't drift apart.                                                      |
| 2026-11-28 | NestJS **11** (not 12)                                                                                           | NestJS 12 is recent; 11.2.x is maintained and its APIs are well known, which lowers risk for an interview deadline.                                                                                                   |
| 2026-11-28 | Zod schemas shared by API validation (`ZodPipe`) and web forms; Swagger generated from them                      | One source of truth: the frontend and backend can't disagree about what's valid, and no duplicate DTO classes.                                                                                                        |
| 2026-11-28 | Session = API-issued **JWT in an httpOnly cookie**; browser → API via the web app's **same-origin `/api` proxy** | First-party cookie, no CORS or third-party cookie issues; server components call the API directly and forward the cookie. The web middleware verifies the JWT for routing only, and the API authorises every request. |
| 2026-11-28 | `AUTH_RATE_LIMIT` (default 10/min per IP) on login and register                                                  | Brute-force protection. Tests and E2E raise it because they register many brokers from one IP. A test proves 429 is returned.                                                                                         |
| 2026-11-28 | `consistent-type-imports` lint rule **off for the API**                                                          | Nest dependency injection reads constructor types at runtime; auto-fixing those imports to `import type` would silently break injection.                                                                              |
| 2026-11-28 | Zod kept out of browser bundles (split `filter-utils`, `figures`, `limits`; auth schemas lazy-loaded)            | After the split, Zod leaked into every page. Fixed: /notes 328→226 kB, editor 450→345 kB, login 228→125 kB.                                                                                                           |
| 2026-11-28 | CSV filenames dated by the **Sydney** calendar                                                                   | Found while testing the API: a 6pm UTC export on the 27th was named for the 27th, but it's already the 28th in Sydney.                                                                                                |
| 2026-11-28 | `next build` without `--turbopack`                                                                               | The webpack production build is the more proven option for deployment.                                                                                                                                                |

## Open issues, TODOs and known limitations

- `npm audit` reports issues in the copy of `postcss` that ships inside Next 15. It only runs at build time, on our own CSS, so the risk is low. Fixing it needs Next 16 (a breaking upgrade), so it's deferred and will be reviewed before deploy.
- The dev machine's C: drive ran out of space during setup. Clearing the npm cache freed about 1.8 GB. Consider `npm config set cache D:\npm-cache`.
- `/notes/new` shows a 404 until Phase 2.
- **Rotate the Neon DB password before deploying.** The current connection string was shared in the AI chat.
- `npm audit` lists high-severity advisories in `effect` and `deepmerge-ts`, which come from the **Prisma CLI's** config loader (`prisma` → `@prisma/config`). That's dev and migration tooling only, never in the runtime bundle. Waiting for a patched Prisma 6 release, which Dependabot will raise.
- The editor page loads 179 kB of JavaScript (Tiptap and ProseMirror). That's acceptable for the main editing screen; the toolbar could be lazy-loaded later if needed.
- No version-history UI yet. Snapshots are already recorded; the history drawer arrives in Phase 4.
- **Stale remote branches** (`phase-0/setup`, `phase-1/auth`, two old Dependabot branches) need deleting. The AI's attempt to delete remote branches was blocked by the permission system, so the owner should run `git push origin --delete …`. Auto-delete on merge is on from now.
- Finalising can't be undone by design. Deleting a finalised note is still allowed (it's a soft delete, so the record is kept).
- Next.js warns it "inferred the workspace root" because of a stray `package-lock.json` in the user's home folder (outside the repo). It's harmless; setting `outputFileTracingRoot` triggered a Tailwind ESM-loading bug, so it's left unset.
- Local dev machine: C: is almost full, so `apps/web/.next` is a junction to `D:\brokernotes-build` (local only, gitignored).
- ~~There's no login rate limiting yet.~~ Done in Phase 5 (API throttling on auth routes). Serverless needs a shared store (for example Upstash) for that, so it's a candidate for Phase 6.
- No "forgot password" or email verification; there's no email provider, which is out of scope for the assignment.
